# 多合一布局选择表

由 `src-tauri/src/grid.rs` 计算（单元测试 `print_layout_table` 生成：`cargo test print_layout_table -- --ignored --nocapture`）。

规则：每格比例 = 所选比例 a:b；布局 cols×rows 的合成比例 = (cols·a):(rows·b)。N=2 候选 2×1、1×2；N=3 候选 3×1、1×3；N=4 候选 2×2、4×1、1×4。选合成比例与该模型支持比例的对数距离最小者；并列时按候选顺序（更方正的 2×2、横排优先）。「（裁切）」表示没有精确命中，拆切时每格居中裁到所选比例。比例为「自动」时不能多合一；GPT 选 GIF / SVG 输出时也不能（无法拆切）。

格式：`布局 → 请求比例`。

## 尺寸

- 预览里的尺寸是估算（标「约」）。GPT 实际输出约 1.57MP：1:1 请求 `1024x1024` 实测返回 1254×1254，其余比例与接口像素表一致。Nano 用 Gemini 3 的 1K 尺寸表（实测 4:3 = 1200×896、16:9 = 1376×768），2K / 4K 依次翻倍。
- 拆切后「放大到单张原尺寸」以**下载到的合成图实际像素**为准：目标 = 该模型的单张尺寸 × √(实际合成面积 / 预期合成面积)，每格按目标尺寸的比例居中裁切后用 fast_image_resize 的 Lanczos3 缩放。
- Nano「合图使用更高一档分辨率」：例如 1K × 4 张用 2K 请求，2K 合图切 4 格正好是原生 1K，不靠放大。
