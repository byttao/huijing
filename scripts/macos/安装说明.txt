绘境 · macOS 安装说明

方法一（推荐）：双击「通用安装-去隔离.command」
  脚本会把「绘境.app」复制到「应用程序」文件夹，清除隔离属性，然后自动打开。
  如果系统提示无法打开这个脚本：右键点它 → 打开 → 再点「打开」。

方法二：把「绘境.app」拖到「Applications」文件夹。
  首次打开若提示「无法验证开发者」或「已损坏」，在终端执行：
  xattr -cr "/Applications/绘境.app"

首次使用：打开后到「设置」填写 GRSAI 的 API Key，点「测试连接」（不扣费）确认可用。
生成的图片默认保存在「图片/绘境」文件夹，可在设置里修改。

应用同时支持 Apple 芯片和 Intel 芯片的 Mac，需要 macOS 10.15 或更新版本。
